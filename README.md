Nome do Projeto: Cheguei - Comi

O processo de criação do Site para uma cantina de faculdade:

1) Qual é o probelma e a solução: Um problema que estava acontecendo no estabelecimento onde realizamos uma vestoria eram as gandes filas, falta de tempo dos estudantes comerem e aproveitarem o seu intervalo de 10 minutos, com isso veio a solução do nosso programa, onde veio como uma facilitador tanto para o estudantes quanto para as pessoas das continas, onde os alunos a distancia podem já escolher e pagar, sem precisarem estar presente no local.

2)  Como executamos: É simples de usar pois, é basicamente um cardápio online. Sua principal função é a de fazer pedidos específicos das cantinas da unibrasil, com as funções básicas de: adicionar itens a uma lista assim como a forma de pagamento e a cantina a qual você quer retirar o seu pedido, por fim relatando todos estes fatores assim como valor do pedido em umm relatório Json.
   
4)  Quais os integrantes e tecnologias usadas: Miguel Stelmach, Laura Casteleins, Emanoel Walek, Carlos Henrique. Utilizamos o compilador Visual studio code, com as linguagens html, css, javascript e json.
